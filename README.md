# \# Insurance Claims Anomaly Detection

# 

# \## Problem

# Detect fraudulent insurance claims to reduce financial losses.

# 

# \## Data

# \- 100k+ claims records

# \- Features: claim\_amount, policy\_type, customer\_age, etc.

# 

# \## Approach

# \- Preprocessing: fraud-risk feature engineering, one-hot encoding

# \- Models: Gradient Boosting Classifier

# \- Evaluation: Precision, Recall, F1-score

# 

# \## Results

# \- Improved detection accuracy by 12%

# \- Reduced false positives

# 

# \## Deployment

# \- Integrated outputs into Power BI dashboards

#
